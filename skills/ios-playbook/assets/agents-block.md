## iOS Playbook

For any change that is more than a one-line edit, use the `ios-playbook` skill: size the risk, read before planning, show the plan, work in small slices, verify each slice, report with evidence.

- Build and test commands, settings and patterns for this repo: `.playbook/repo-map.md`
- Fragile areas and what to check around them: `.playbook/risk-map.md`
- Saved plans: `.playbook/plans/`

If the repo map is missing, run the skill in `map` mode first. If a command in the map fails, fix the map.
