Most failed iOS changes are process failures: editing before reading the project, fixing a bug without reproducing it, one giant diff, and "done" without a build. This playbook makes the agent size the risk, plan in small slices, verify each one and report with evidence.

The loop

Six steps, sized to the task.

00

Size

Trivial, standard or high risk. A typo fix stays cheap. A schema change on a shipped store gets the full process and your approval first.

01

Read

Deployment target, Swift mode, default isolation, schemes, the pattern already in use, a baseline build. For a bug, a reproduction before any fix.

02

Plan

Goal, scope, assumptions marked verified or not, slices with their gates, and the things the compiler will not catch.

03

Slice

One concept per slice. Each one builds and passes on its own. Refactors and migrations never share a slice with anything else.

04

Verify

Build, targeted tests, a test that fails first, a migration test against the shipped store, Thread Sanitizer, a UI walk, previews, a diff audit.

05

Report

What changed, the command and result behind every claim, what was not verified, and what was noticed but left alone.

One command

Map once. Plan with your best model. Execute with a cheaper one.

CommandWhat it does
/ios-playbook mapReads the repo and writes a repo map (working build commands, settings, patterns) and a risk map (where changes break silently). Every later session starts from facts.
/ios-playbook plan <task>Plan only, saved to a file. Written so another model or a fresh session can execute it without making design decisions.
/ios-playbook execute <file>Carries out a saved plan one verified slice at a time, and stops if the plan no longer matches the code.
/ios-playbook verifyRuns the gates on the current working tree and reports. No edits.
/ios-playbook <task>The whole loop, from sizing to report.

One line

Start using it in minutes.

curl -fsSL https://sahinraj.github.io/ios-agent-playbook/install.sh | bash

The script installs for Claude Code and Copilot, whichever you have. For Copilot for Xcode or a team repository, run curl -fsSL https://sahinraj.github.io/ios-agent-playbook/install.sh | bash -s -- project ~/path/to/YourApp. Prefer to read the script first? Clone the repo and run ./install.sh personal.
